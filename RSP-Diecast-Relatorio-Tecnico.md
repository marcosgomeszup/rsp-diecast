# 🏎️ RSP Diecast / Coleção Racing

**Sistema Web e PWA para cadastro e gestão de carros de competição e miniaturas.**

[https://rspdiecast.com.br](https://rspdiecast.com.br)

---

## 🚀 Sobre o Projeto

O **RSP Diecast** é um sistema completo desenvolvido para catalogar, exibir e analisar coleções de carros de competição e miniaturas.  
Conta com autenticação Google, upload direto de imagens, exportação de relatórios e dashboard de estatísticas interativo.

O projeto foi criado com base na identidade visual da **Williams F1**, utilizando tons de **azul escuro, azul claro e branco**.

---

## 🧩 Principais Funcionalidades

- Login híbrido (Google + local)
- Cadastro completo de carros e miniaturas
- Upload de imagens (desktop, celular e web)
- Exportação de relatórios (CSV / XLSX)
- Dashboard com gráficos e KPIs
- Interface responsiva e instalável (PWA)

---

## 🏗️ Stack Tecnológica

| Camada | Tecnologia |
|---------|-------------|
| Backend | Laravel 11 (PHP 8.4) |
| Frontend | Blade + Tailwind CSS |
| Banco de Dados | MySQL 8 |
| PWA | Manifest + Service Worker |
| Exportação | Laravel Excel |
| Autenticação | Laravel Socialite (Google) |
